## Project description (paragraph — for Experience or Featured)

Built **TechZone.pk**, a full-stack eCommerce system in PHP and MySQL. Delivered a customer-facing store (product catalog, cart, checkout, login, orders, reviews) and a secure admin dashboard with analytics (Chart.js), order and product management, categories, customers, and contact messages. Implemented security best practices: PDO prepared statements, CSRF protection on forms, session-based authentication, and route protection. Used a shared core layer for database and inventory logic across both applications. Responsive UI with Bootstrap 5 and a consistent design system.
